# Typography revision prompts

Tool: built-in image_gen. Reference: `sources/existing-style-reference.png`. Only the headline inside its blue artwork card is the typography reference; the black App Store viewer surround is excluded. The selected outputs replace the files in `generated/` and the final exports.

## backword

```text
Use case: text-localization / precise typography edit.
Input image 1 is the edit target, an existing promotional artwork. Input image 2 is the AUTHORITATIVE FONT AND FONT-SIZE REFERENCE. It is a phone capture showing an App Store carousel: the reference artwork is ONLY the large blue rounded card, x≈10–90% and y≈14–94%. The surrounding black viewer, outer phone status bar, close button and adjacent card are NOT part of the artwork.
Edit ONLY the white promotional headline above the device in image 1. Match the EXACT visual typeface, weight and RELATIVE FONT SIZE of the headline "Guess the Backword in / 5 attempts" inside the blue card of input 2. Its lettering is compact rounded geometric sans-serif bold, similar to Outfit Bold 700, distinctly less heavy and about 30% smaller than the current input 1 headline. Match the reference letter shapes, normal spacing and weight; no extra-bold inflated or very wide letters.
Quantitative size: normalize the reference card width to the output canvas width (ignore its black viewer margins). Capital letter height is approximately 4.4% of the FULL ARTWORK WIDTH; nominal font size about 6.3% of artwork width, line advance about 8.2% of artwork width. On 1242px artwork this means font roughly 78px, actual capital height about 55px, baseline-to-baseline roughly 100px. Apply the same proportional size on the iPad canvas (font roughly 130px, capitals 91px). Do NOT enlarge short lines or fit the headline to the width. Keep each asset at this fixed relative type size, including Midword.
Center the headline horizontally. Position the overall headline block around 8.5% of canvas height, preserving generous blue space above the device like the reference. Exact caption lines are specified below.
Preserve EVERYTHING ELSE in image 1 unchanged: the current muted blue-to-dark-teal gradient, matte black device frame, shadow, device placement and size, complete app screen, all UI colors, text, logos, grid cells, letter tiles, icons and keyboard. No changes inside the device. Do not copy the old reference gameplay or caption into the device. Do not add black viewer surround, rounded canvas corners, badges, ornaments or watermark. Smooth opaque PNG.
Output portrait 1242×2688. Exact headline lines, verbatim, no other words:
"Guess forwards."
"Reveal backwards."
```
